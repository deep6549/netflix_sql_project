# Netflix SQL Data Analysis

## 📌 Project Overview

This project analyzes the Netflix titles dataset using **PostgreSQL** to explore trends and patterns across movies and TV shows.

The analysis focuses on content types, ratings, release years, countries, genres, directors, duration, and other attributes available in the dataset.

The project contains **29 SQL analysis queries**, ranging from basic filtering and aggregation to subqueries, CTEs, window functions, string manipulation, and date-based analysis.

---

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows on Netflix
- Identify common ratings and content trends
- Analyze Netflix content by country and release year
- Explore genres and genre diversity
- Find directors and creators associated with Netflix titles
- Analyze movie durations and TV show seasons
- Perform date-based analysis of Netflix additions
- Practice advanced SQL techniques using a real-world dataset
